JacRed — это самохостируемое .NET-приложение, которое собирает раздачи с 25 русскоязычных и аниме-трекеров, хранит их в локальной файловой базе данных FileDB и предоставляет единый поисковый API, совместимый с Jackett, Torznab и Prowlarr. Подключите его к Lampa, Sonarr, Radarr или любому другому клиенту и ищите торренты через один эндпоинт.

## Архитектура

JacRed состоит из трёх слоев:

1. **Крон-парсеры** — HTTP-вызовы к `/cron/{slug}/parse` по расписанию из `Data/crontab`. Парсят трекеры и записывают раздачи в FileDB.
2. **FileDB** — JSON-файлы в `Data/fdb/`, шардированные по MD5-хешу ключа. In-memory индекс `masterDb` для быстрого поиска.
3. **API** — ASP.NET на порту 9117. Обрабатывает поисковые запросы, управление конфигом и синхронизацию.
