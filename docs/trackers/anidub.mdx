Anidub, slug `anidub`, содержит около 4 тысяч раздач и работает без авторизации. Использует page-range кластер (только `parse`).

## Конфигурация

```yaml
Anidub:
  host: https://tr.anidub.com
  useproxy: false
  reqMinute: 8
  parseDelay: 7000
  log: true
```

## Расписание cron

```crontab
4,19,34,49 * * * *  /opt/jacred/Data/run-job.sh anidub-parse http://127.0.0.1:9117/cron/anidub/parse 900
```

## Диагностика

```bash
curl "http://localhost:9117/cron/anidub/parse"
tail -f /opt/jacred/Data/log/anidub.log
```
