Viruseproject, slug `viruseproject`, работает без авторизации. Кластер ежедневного `parse` с `limit_page`. Раздачи скачиваются как `.torrent` и превращаются в магнет (`t→M`).

## Конфигурация

```yaml
Viruseproject:
  host: https://viruseproject.tv
  alias: ""
  useproxy: false
  reqMinute: 8
  parseDelay: 7000
  log: true
```

- `host` задаёт основной адрес.
- `alias` заменяет адрес запросов.
- `useproxy` применяет глобальный прокси.
- `parseDelay` задаёт паузу между страницами категорий.

Не добавляйте логины или cookie.

## Действия парсера

| Путь | Назначение |
| --- | --- |
| `/cron/viruseproject/Parse` | Обойти категории. `limit_page` ≤ 0 читает последнюю страницу пагинации |

<ParamField path="query.limit_page" default="3" type="number">
  Максимальное число страниц на категорию за запуск. В crontab задано 3.
</ParamField>

## Расписание

Стандартный `Data/crontab` использует:

```crontab
50 6 * * *  /opt/jacred/Data/run-job.sh viruseproject-parse "http://127.0.0.1:9117/cron/viruseproject/parse?limit_page=3" 900
```

## Диагностика

```bash
curl "http://127.0.0.1:9117/cron/viruseproject/parse?limit_page=3"
curl http://127.0.0.1:9117/health/background-jobs
tail -f /opt/jacred/Data/log/viruseproject.log
```

Если запросы не проходят, проверьте `host`, `alias` и [настройку прокси](/configuration/proxy). Если endpoint возвращает `401` или `403`, проверьте [матрицу доступа](/operations/access-matrix).
