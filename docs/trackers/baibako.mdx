Baibako, slug `baibako`, содержит около 5 тысяч раздач с низкой частотой обновлений. Требует авторизации через cookie или логин/пароль. Использует page-range кластер (только `parse`, страницы с нуля). Преемник сериального каталога — slug [`rudub`](/trackers/rudub). Не переназначайте `baibako` на RuDub.

<Warning>
  В `AppOptions` парсер помечен как `TODO: fix parser`. Считайте интеграцию нестабильной, пока эта пометка не снята. Для HD-сериалов используйте [Rudub](/trackers/rudub).
</Warning>

## Конфигурация

<CodeGroup>

```yaml Cookie
Baibako:
  host: http://baibako.tv
  useproxy: false
  reqMinute: 8
  parseDelay: 7000
  log: true
  cookie: "PHPSESSID=SESSION; uid=USER_ID; pass=PASS_HASH"
```

```yaml Логин/пароль
Baibako:
  host: http://baibako.tv
  useproxy: false
  reqMinute: 8
  parseDelay: 7000
  log: true
  login:
    u: "mylogin"
    p: "mypassword"
```

</CodeGroup>

## Расписание cron

```crontab
8,23,38,53 * * * *  /opt/jacred/Data/run-job.sh baibako-parse http://127.0.0.1:9117/cron/baibako/parse 900
```

<ParamField path="query.parseFrom" type="number" default="0">
  Начальная страница. Нумерация с нуля.
</ParamField>

<ParamField path="query.parseTo" type="number" default="0">
  Конечная страница. 0 совпадает с `parseFrom`.
</ParamField>

## Диагностика

```bash
curl http://127.0.0.1:9117/cron/baibako/parse
curl http://127.0.0.1:9117/health/background-jobs
tail -f /opt/jacred/Data/log/baibako.log
```

Если запросы не проходят, проверьте cookie/login и [настройку прокси](/configuration/proxy). Если endpoint возвращает `401` или `403`, проверьте [матрицу доступа](/operations/access-matrix).
